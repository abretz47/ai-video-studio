# restart job

## User Prompt

> restart job

## Goals

Add a "restart render job" capability so operators can retry any failed or cancelled render job by ID, without manually re-queuing with the same preset. Expose the action both as a backend API endpoint and as a per-job button in the render panel history list.

## Changes

### Backend

- **`ai-pic-backend/app/services/timeline_lifecycle_service.py`**
  - Added `restart_render_job(timeline_id, render_job_id, current_user)` method.
  - Validates job status is `failed` or `cancelled` (raises 409 otherwise).
  - Soft-deletes the old job with reason `"restarted"`, creates a new `queued` job with the same preset/render_type/timeline_version, then dispatches it via `dispatch_timeline_render_job`.
  - Imported `dispatch_timeline_render_job` and `render_preset_hash`.

- **`ai-pic-backend/app/api/v1/endpoints/timelines.py`**
  - Added `POST /timelines/{timeline_id}/render-jobs/{render_job_id}/restart` endpoint calling `TimelineLifecycleService.restart_render_job`.

- **`ai-pic-backend/tests/test_timeline_lifecycle_api.py`**
  - `test_render_job_restart_creates_new_queued_job` — verifies restart soft-deletes failed job, creates new queued job with same preset, dispatches it.
  - `test_render_job_restart_rejected_for_non_failed_job` — verifies 409 for jobs in `queued`/`running`/`succeeded` status.

### Frontend

- **`ai-pic-frontend/src/utils/api/endpoints/timeline.endpoints.ts`**
  - Added `restartTimelineRenderJob(timelineId, renderJobId)` API function.
  - Exported it via `timelineAPI`.

- **`ai-pic-frontend/src/components/features/episode/useTimelineRenderJobs.ts`**
  - Added `restartRenderJob(renderJobId)` callback.
  - Now returns `renderJobs` (full list) in addition to `latestJob`.

- **`ai-pic-frontend/src/components/features/episode/EpisodeTimelineRenderPanelParts.tsx`**
  - Exported `renderStatusLabel` and added `renderJobHistoryClass` helper (used by history list).

- **`ai-pic-frontend/src/components/features/episode/EpisodeTimelineRenderPanel.tsx`**
  - Accepts `renderJobs` and `onRestartRenderJob` props.
  - Shows a collapsible "Job history" list when there are multiple jobs; each failed/cancelled entry has a Restart button.

- **`ai-pic-frontend/src/components/features/episode/EpisodeTimelineMainPanel.tsx`**
  - Threads `renderJobs` and `onRestartRenderJob` down to `TimelineRenderPanel`.

- **`ai-pic-frontend/src/components/features/episode/EpisodeTimelineWorkspacePanels.tsx`**
  - Threads `renderJobs` and `onRestartRenderJob` through.

- **`ai-pic-frontend/src/components/features/episode/EpisodeTimelineWorkspace.tsx`**
  - Destructures `renderJobs` and `restartRenderJob` from hook; passes `onRestartRenderJob` down.
