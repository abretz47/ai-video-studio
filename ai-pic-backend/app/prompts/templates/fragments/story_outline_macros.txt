{#- ============= SHORT DRAMA REQUIREMENTS ============= -#}
{%- macro short_drama_requirements() -%}
## 【Hard Short-Drama Requirements】Every Episode Must Have a Payoff
Please design the entire short drama as a serialized binge-driving structure of "every episode must have a payoff + an ending cliffhanger":

1. **Opening hook**: within the first 10 seconds, a high-conflict / high-information event must happen (catching cheating, betrayal, identity exposure, benefit collapse, etc.).
2. **Payoff lands**: every episode must contain at least 1 clear, shootable payoff event (humiliation reversal / counterattack / reveal / punishment / reversal / confession / rescue, etc.), not just abstract emotion.
3. **Ending cliffhanger**: each episode must end with a bigger suspense beat or escalated crisis that strongly drives the next episode.
4. **Editability**: payoff beats and cliffhangers should be splittable into 15/30/60-second traffic assets (dialogue hook + visual action + CTA).
{%- endmacro -%}

{#- ============= GENERATION FIELDS DESCRIPTION ============= -#}
{%- macro generation_fields_description(format_type="default") -%}
## Content to Generate
Please create a complete {% if format_type == "short_drama" %}short drama{% elif format_type == "film" %}film{% elif format_type == "tv_series" %}TV series{% else %}{% endif %} story outline and return it in JSON format, including the following content:

1. **Story premise** (premise): the core concept and foundational setup of the story
2. **Detailed synopsis** (synopsis): a complete plot summary including setup, development, turn, and resolution{% if format_type == "short_drama" %}, while also reflecting short-drama pacing and binge-driving momentum{% endif %}
3. **Main conflict** (main_conflict): the story's core conflict and contradiction
4. **Resolution** (resolution): the way the conflict is resolved{% if format_type == "short_drama" %} / ending direction (it may resolve in stages to support multi-episode follow-through){% else %} and the story ending{% endif %}
5. **Character relationships** (character_relationships): the relationship web among the main characters
6. **Main character info** (main_characters): the reorganized information for the main characters
7. **Plot structure** (plot_structure): the story's three-act structural breakdown{% if format_type == "short_drama" %} (used as the overall narrative skeleton){% endif %}
8. **Core values** (core_values): the values and meaning the story aims to convey
9. **Visual style** (visual_style): suitable recommendations for the visual presentation style{% if format_type == "short_drama" %} (camera / art direction / lighting){% endif %}
10. **Selling points** (selling_points): the story highlights{% if format_type == "short_drama" %} and traffic-oriented selling points (at least 5 items, including payoff types){% else %} and the elements that attract audiences{% endif %}
11. **Payoff pacing** (hook_plan): opening hook, emotional build-up and release, and key reversal planning{% if format_type == "short_drama" %} (must reflect the rule of "every episode must have a payoff + an ending cliffhanger"){% endif %}
12. **Twist density** (twist_density): the target reversal density (plain text is fine)
13. **Cliffhanger beats** (cliffhanger_plan): a list of key cliffhangers / suspense beats{% if format_type == "short_drama" %} (at least 6 items){% endif %}
14. **Traffic assets** (ad_snippets): hooks, visual summaries, and CTA suggestions for 15/30/60-second assets{% if format_type == "short_drama" %} (at least 3 items){% endif %}
{%- endmacro -%}
