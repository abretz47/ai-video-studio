{#- ============= SCRIPT FORMAT REQUIREMENTS ============= -#}
{%- macro script_format_requirements(format_type="default") -%}
## Script Format Requirements

### Basic Format
1. Scene heading: [INT/EXT] [Location] [Time]
2. Action description: present tense, third person
3. Character dialogue: Character Name: dialogue line
4. Parenthetical notes: (action / emotion / tone cues)

### Dialogue Standards
- Keep each line within 15 Chinese characters when possible (suitable for TTS synthesis)
- Avoid written-language stiffness; use colloquial expression
- Dialogue should match the character's personality and identity
- Use markers such as (pause) or (emphasis) when necessary
{% if format_type == "short_drama" -%}

### Special Requirements for Short Drama
- There must be conflict or suspense within the first 3 seconds
- At least one plot turn per minute
- Dialogue should have "quotable line" potential suitable for traffic assets
- The ending must leave suspense
{% endif -%}
{%- endmacro -%}

{#- ============= VISUAL DESCRIPTION REQUIREMENTS ============= -#}
{%- macro visual_requirements() -%}
## Visual Description Standards
1. **Shootability**: all descriptions must be practically filmable
2. **Specific action**: use specific verbs instead of abstract descriptions
   - ✓ "Zhang San jumps to his feet and storms out, slamming the door"
   - ✗ "Zhang San shows anger"
3. **Shot awareness**: imply the composition of key visuals
4. **Detail cues**: provide important props, expressions, and action details
5. **No inner monologue narration**: do not directly describe the character's inner thoughts
{%- endmacro -%}

{#- ============= DIALOGUE QUALITY REQUIREMENTS ============= -#}
{%- macro dialogue_quality_requirements() -%}
## Dialogue Quality Standards
1. **Show, don't tell**: reveal emotion through action and dialogue instead of direct statement
   - ✓ "Why are you working late again?" (concerned but worried)
   - ✗ "I am very worried about your health." (direct statement)

2. **Subtext**: dialogue should carry implied meaning
   - ✓ "It's getting late." (implies it's time to leave)
   - ✗ "You should go now." (direct command)

3. **Character voice**: each character's speaking style should be distinguishable

4. **Information efficiency**: every line of dialogue should advance the plot or reveal character
{%- endmacro -%}

{#- ============= SCRIPT OUTPUT FORMAT ============= -#}
{%- macro script_output_format() -%}
## Output Format
Please output in standard script format:

```
[INT] Office - Day

Zhang San sits at his desk, frowning as he stares at the computer screen.

Li Si pushes the door open and walks in.

Li Si: (softly) Still not off work?

Zhang San: (without looking up) What is it?

Li Si places a document on the desk.

Li Si: Take a look at this.

Zhang San picks up the document, and his expression changes sharply.

Zhang San: Th... this is real?

【CUT TO】
```
{%- endmacro -%}
