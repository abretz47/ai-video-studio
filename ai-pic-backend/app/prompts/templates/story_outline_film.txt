## Generated content
Please return a complete film story outline in JSON format, including the following:

1. **Story premise** (`premise`): the core concept and setup

3. **Main conflict** (`main_conflict`): the main conflict and opposition (make the opponent/resistance explicit)
4. **Resolution** (`resolution`): the resolution of the conflict and the thematic landing point (make the ending's emotional texture explicit)
5. **Character relationships** (`character_relationships`): relationship web among the main characters
6. **Main character information** (`main_characters`): main character information (motivation / arc)
7. **Plot structure** (`plot_structure`): three-act structure (including key turning points)
8. **Core values** (`core_values`): thematic expression and emotional core
9. **Visual style** (`visual_style`): suggestions for cinematic visual expression (camera / art direction / lighting / color grading)
10. **Selling points** (`selling_points`): selling points and highlights (genre highlights, visual highlights, emotional highlights)
11. **Payoff rhythm** (`hook_plan`): if payoff/twist planning is provided, map it to key sections
12. **Twist density** (`twist_density`): target twist density (if available)
13. **Cliffhanger plan** (`cliffhanger_plan`): key suspense beats (if available; can be section-level beats)
14. **Ad assets** (`ad_snippets`): hooks, visual summaries, and CTAs for 15/30/60-second assets (if available)

## Creative principles (film)
- Closed narrative loop: clear inciting cause → development → climax → ending, with coherent logic
- Character arc: the protagonist's transformation must be clear, with key beats driving the change
- Cinematic expression: emphasize visual storytelling, pacing, and emotional curve
