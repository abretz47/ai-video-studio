## Task
Analyze how long the pause after each line of dialogue should be (in milliseconds), considering the following factors:

1. **Emotional transition**: if there is a large emotional change between lines (such as anger → calm), a longer pause is needed so the audience can absorb it
2. **Dramatic pacing**: high-conflict scenes usually need shorter pauses to maintain tension; warm scenes need longer pauses
3. **Semantic completeness**: pauses after periods and question marks are usually longer than pauses after commas
4. **Character switching**: dialogue exchanges between different characters may need a slight pause
5. **Action timing**: if there is action description, reserve time for the action

- Recommended range: 200ms - 1500ms
