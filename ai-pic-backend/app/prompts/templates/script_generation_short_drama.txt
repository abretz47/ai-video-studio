## [Mandatory short-drama rules] Every episode must contain a payoff + an ending cliffhanger
You must explicitly achieve the following in this episode script:

1. **Opening hook (first 10 seconds)**: The first scene must contain conflict / a bombshell / an information reveal.
2. **Midpoint escalation**: Escalate the conflict quickly; do not spend too much time on setup dialogue.
3. **Payoff beat (mandatory)**: Include at least 1 clearly filmable payoff event (humiliation reversal / counterattack / reveal / punishment / reversal / rescue / confession).
4. **Ending cliffhanger (mandatory)**: The final scene must leave suspense or escalate into a bigger crisis.
5. **Low-cost shootability**: Reuse locations and characters whenever possible; avoid large crowds and complex VFX.

## Generation requirements
Generate a complete shootable short-drama script and return it in JSON:

- `content`: full script body text. By default, use the commercial vertical short-drama body format:
  `Episode N` / `N-M INT./EXT. Location - Day/Night` / `Characters:` / `▲Action or shot` / `Character (state): Dialogue`.
- `scenes`: scene list (recommended 1-4 scenes); mark payoff scenes with `PAYOFF` in `notes`, and the ending cliffhanger scene with `CLIFFHANGER`
- `dialogues`: dialogue list (high information density, avoid filler and empty lines; do not use "..." to omit dialogue)
- `stage_directions`: stage directions / actions (to support shooting and performance)
- `metadata`: include market_region / micro_genre / hook_plan / twist_density / cliffhanger_plan / ad_snippets, and keep them consistent with the episode content
