Key judgment criteria:
1. **Dialogues**: Lines spoken by characters, direct speech, with a clear speaker. Examples:
   - "Hm? The current reading is fluctuating abnormally." ← This is a character's inner monologue or line
   - "What the hell... electromagnetic interference?" ← This is a character's question / reaction
   - Any sentence with a questioning, exclamatory, or conversational quality

2. **Stage directions**: Non-dialogue content describing actions, scene changes, camera, sound effects, etc. Examples:
   - "The stress test is underway. The data stream on the screen suddenly accelerates." ← Scene description
   - "Suddenly, a pulse of blue current flashes across the room." ← Action description
   - "Cut to the pile of old objects in the corner." ← Camera direction

Common error patterns:
- A character's inner monologue is placed in stage directions
- Reactive lines from a character (such as "Hm?" "What?!" "What's going on") are treated as description
- Direct speech with ellipses, exclamation marks, or question marks is misclassified
