## Output Format
Return JSON with an episodes array. Each episode must include:
- episode_number: Episode number
- title: Episode title
- summary: Episode summary
- plot_points: List of major plot points
- character_arcs: Character development plan
- conflicts: Conflicts in this episode
- scene_count: Estimated number of scenes
- scenes: Scene list (array), each containing at least scene_number, slug_line (for example INT. OFFICE - DAY), location, time_of_day, summary

Example format:
{
    "episodes": [
        {
            "episode_number": 1,
            "title": "A New Beginning",
            "summary": "Introduces the main characters and the world of the story",
            "plot_points": [{"description": "Character introduction", "timing": "Opening"}],
            "character_arcs": {"protagonist": "Initial state is established"},
            "conflicts": [{"description": "Inner turmoil", "intensity": "low"}],
            "scene_count": 5,
            "scenes": [
                {
                    "scene_number": 1,
                    "slug_line": "INT. OFFICE - DAY",
                    "location": "Company headquarters office",
                    "time_of_day": "day",
                    "summary": "Scene summary establishing the characters and conflict setup"
                }
            ]
        }
    ]
}
